# SkyBank

Приложение для анализа транзакций, которые находятся в Excel-файле.

## Зависимости:

requests = "^2.32.3"
flake8 = "^7.1.1"
mypy = "^1.13.0"
black = "^24.10.0"
isort = "^5.13.2"
pytest-cov = "^6.0.0"

### Функции в программе:

1. Чтение транзакций из Excel-файла
2. Вывод информации по каждой карте пользователя
3. Получение данных об акциях из списка S&P500
4. Получение данных об актуальном курсе валют
5. Поиск транзакций, содержащих мобильные номера
6. Получение данных о тратах за последние три месяца

## Тесты:

Проведены тесты всех функций. Все тесты находятся в пакете tests.
Все тесты запускаются по команде: pytest
Coverage report: 94%
